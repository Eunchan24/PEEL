# PEEL: Peeling the Matryoshka

> **Peeling the Matryoshka: Extracting Ontological Structure from Retrieval Embeddings**

Code and data for the PEEL paper.

## Overview

**PEEL** (Peeling Embeddings to Extract Latent Ontologies) is a lightweight method that extracts taxonomic structure directly from pre-trained Matryoshka Representation Learning (MRL) embeddings using a 98K-parameter linear projection and Chu-Liu-Edmonds maximum spanning arborescence.
